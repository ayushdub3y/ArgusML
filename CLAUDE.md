\## Non-negotiable invariants

\- Deterministic vs ML vs LLM boundary is fixed by §3. Model A and Model B

&#x20; never choose accept/contest/escalate — only decision\_engine.py sets

&#x20; that outcome.

\- §6 EV rule and §6b velocity/cumulative-exposure gate are both

&#x20; deterministic and both required before any auto-accept fires. The

&#x20; velocity gate runs BEFORE the EV rule's accept branch.

\- Every auto-accept requires one human tap

&#x20; (src/human\_review/accept\_checkpoint.py): one reasoning line, expandable

&#x20; to full SHAP/logs. No silent full-auto accepts.

\- The deadline watchdog (§2) may bypass the human tap under time

&#x20; pressure. It must never bypass the velocity gate.

\- Model B only drafts text; validate\_facts.py hard-blocks any generated

&#x20; field not present in the source evidence record (§5, §12).

\- Sandbox/test-mode Razorpay API only. No production bank/NPCI

&#x20; integration (§13).

\- No second loss-class module. Extensions (§13) get one prose paragraph

&#x20; in README, never code.

\- Repo tree is §8, authoritative. Don't add top-level dirs/files without

&#x20; asking first.



\## Working norms

\- Plan first (plan mode) for anything with a real design decision: model

&#x20; choice, thresholds, schema. Skip planning for pure boilerplate.

\- One component per session/commit. Don't bundle unrelated files.

\- If a wrong assumption gets caught and corrected mid-build, log it in

&#x20; FAILURE\_LOG.md: date, what was wrong, what fixed it, source. This is a

&#x20; graded deliverable, not cleanup.

\- METRICS.md is only ever regenerated by eval/run\_eval.py — never

&#x20; hand-edited.

\- Python: type hints + docstrings; docstrings cite the ARCHITECTURE.md

&#x20; section they implement, e.g. "Implements §6b cumulative-exposure gate."

\- No placeholder/mock business logic in P0 code paths. If something

&#x20; can't be done for real yet, raise NotImplementedError with a comment —

&#x20; don't fake a return value.
